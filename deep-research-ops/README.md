# deep-research-ops (Codex plugin)

Multi-step research workflow over any search MCP servers; installs web-search-dev for the tools.

## Install

```bash
codex plugin marketplace add agents-store/deep-research-ops-codex
```

Or for local development:

```bash
codex plugin marketplace add .
```

## Components

- 11 skill(s) under `skills/` (includes 6 command(s) converted to skills — Codex has no custom slash-command system)
- No MCP server
- No hooks
